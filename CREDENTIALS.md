# Lab credentials

Credentials are intentionally retained at the repository owner's request.

## Root SSH

```text
Host: 192.168.1.254
User: root
Password: admin
Port: 22
Scope: LAN only
```

The included decrypted configuration files also retain their original
device-specific settings, password hashes, Wi-Fi keys, ACS credentials, serial
number, and related provisioning values.
